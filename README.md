# Flourish

This folder is the whole app. It does not need Grok, an account, or a server. Your ticks, goals and deadlines stay on the phone.

## Put it on the internet for free

You only do this once, so the Home Screen icon has a link that keeps working.

The source already lives in [github.com/obensonflorice2016-a11y/flourish](https://github.com/obensonflorice2016-a11y/flourish). To publish that copy, open the repo, then **Settings**, then **Pages**, and set the source to **GitHub Actions**. The install link is `https://obensonflorice2016-a11y.github.io/flourish/`.

If you are starting again from the zip instead:

1. Unzip it. You should see `index.html` in that folder.
2. Create a public GitHub repository named `flourish`.
3. Upload every file from the unzipped folder. Do not upload the zip itself.
4. Open **Settings**, then **Pages**. Choose branch **main** and folder **/ (root)**. Save.
5. Wait a minute. Your link will look like `https://yourname.github.io/flourish/`.

### B. Netlify Drop, if GitHub feels like a lot

1. Unzip this folder on your computer if it is still a zip.
2. Open [https://app.netlify.com/drop](https://app.netlify.com/drop).
3. Drag the **folder** (the one that contains `index.html`) onto the page.
4. Netlify gives you a link. That link is your app. You can rename it later if you make a free Netlify account.

## C. Install it, on any device, from the same link

The link is the same one for every device: `https://obensonflorice2016-a11y.github.io/flourish/`

If that page is not up yet, open the GitHub repo, go to Settings, then Pages, and set the source to **GitHub Actions**. Or unzip the source zip and drag that folder onto [Netlify Drop](https://app.netlify.com/drop).

- **iPhone:** open the link in Safari. Tap Share, then Add to Home Screen.
- **Android:** open the link in Chrome. Tap Install app, or the browser menu, then Install app.
- **Windows laptop:** open the link in Chrome or Edge. Use the Install icon in the address bar, or the menu, then Install.

Inside the app, Plan has the same steps, near the bottom under This phone. Plan also has **Save a source zip**, which is this whole app in one file. Save that zip in Google Drive or OneDrive. If the link ever stops, unzip it and host the folder again (GitHub Pages from the `main` branch, root, or Netlify Drop).

The full source is also kept at [github.com/obensonflorice2016-a11y/flourish](https://github.com/obensonflorice2016-a11y/flourish).

## D. Back up and restore

1. Open Plan, and scroll to This phone. Or use the backup note on Today when a week has passed.
2. Tap **Back up to file**. A dated JSON file is offered. It holds every tick, goal, score, note, and deadline on this device.
3. On a phone, the share sheet can save straight into Google Drive or OneDrive. On a laptop, the save window can put the file in the Drive or OneDrive folder.
4. The home screen says how many days ago the last backup was. Every Sunday, Flourish asks again. Add to my calendar includes a Sunday backup reminder.
5. On a new device: install from the link, open Plan, tap **Restore from file**, and choose that JSON from Drive or OneDrive. Confirm. Your ticks, goals and deadlines come back.

Reminders and the calendar file are on Plan, under This phone. Sunday and Monday stay free of tasks. The Sunday note is only the backup reminder.
